# GeoPekalongan — Dashboard Analisis Spasial

**ETS Pemrograman Spasial A | Kelompok 17**

## Deskripsi Proyek

GeoPekalongan merupakan dashboard interaktif berbasis R Shiny untuk menampilkan dan menganalisis tutupan lahan serta indeks spektral di Kabupaten Pekalongan menggunakan data citra Sentinel-2.

## Fitur Utama

- Peta klasifikasi tutupan lahan: vegetasi, bangunan, perairan, dan awan.
- Visualisasi indeks spektral NDVI, NDBI, NDWI, dan NDCI.
- Peta interaktif dengan pilihan OpenStreetMap dan citra satelit.
- Visualisasi batas administrasi kabupaten dan kecamatan.
- Statistik spasial dan fitur unduh data.

## Teknologi

R, Shiny, shinydashboard, Leaflet, terra, dan sf.
